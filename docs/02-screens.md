# 02 · 화면 구성

탭 3개: **카메라 / 히스토리 / 설정**

## 탭 1 — 카메라 (기본 진입)

### 온보딩 (최초 1회)

- `My 💩` / `My Baby 💩` 두 버튼 선택
- 선택값 LocalStorage 저장, 이후 스킵
- 좌상단 `< 이전` 버튼 항상 표시

### 촬영 플로우

```
카메라 열림
  → 변기 / 기저귀 인식
  → 해당 영역 실시간 가리기 (모자이크 or 스티커)
  → 촬영 버튼
  → 로딩 (AI 분석 중)
  → 결과 화면
      ├── 별점 (★ 0~5, 0.5 단위)
      ├── AI 코멘트 (건강하면 드립 랜덤)
      └── 이상 소견 시 추가 질문 팝업 + 입력칸
            "오늘 뭐 드셨어요?"
            "약 드시는 거 있으세요?"
            "유당불내증 있으세요?"
```

### UI 요소

- 우상단: 가리기 ON/OFF 토글 (빠른 전환)
- 그 옆: 모자이크 ↔ 스티커 전환
- 가리기 기본값 ON (설정에서 변경)

## 탭 2 — 히스토리

- **상단** 꺾은선 그래프 — X축 날짜(7일/30일), Y축 별점(0~5). 점 클릭 시 상세 팝업
- **중단** 캘린더 뷰 — 날짜별 상태 도트
  - 양호(별점 4↑) `status.good`
  - 주의(2.5~3.5) `status.caution`
  - 경고(2↓) `status.warning`
- **하단** AI 7일 총평 — 매번 새로 호출
- 뷰 전환: 7일 / 30일 (오늘 기준, 맨 오른쪽이 오늘)
- 모드 전환: 내 똥 ↔ 베이비 똥 가로 스와이프

## 탭 3 — 설정

```
├── 가리기 설정
│     ├── 기본값: 모자이크 or 스티커
│     ├── 스티커 선택 시: 성인 / 베이비 캐릭터
│     └── 가리기 기본 ON/OFF
├── 마이 건강 정보 등록/수정
├── 마이 베이비 건강 정보 등록/수정
│     └── 베이비풉 촬영 후 바로 여기로 유도
├── 다운로드
│     ├── 전체 / 날짜 선택 / 기간 설정
│     └── 5,000원 결제 (별점 + AI코멘트 + 식사메모 PDF)
├── 언어 설정 (한국어 / English)
├── 로그인 / 로그아웃
│     └── 게스트면 회원가입 유도 (이메일 / Google / 카카오)
└── 개인정보 처리방침 / AI 학습 데이터 활용 동의
```
