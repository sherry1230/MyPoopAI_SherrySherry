# 02 · 화면 구성

> 기준: 기획서 9/4판 §3 화면 상세 + 현행 아키텍처(기록 채팅이 본체).
> 탭 3개: **기록(채팅) / 히스토리 / 설정**. 카메라는 독립 화면이 아니라 첨부 시트.

## 온보딩 플로우

기획서: 모드 선택 → 카메라 → 첫 평가 → 회원가입 유도 (**선체험 퍼널** — 평가를 먼저
보여주고 가입받는다).

- 최초 1회 `My 💩` / `My Baby 💩` 선택, LocalStorage 저장(기기 프리퍼런스), 이후 스킵
- 베이비풉 첫 기록 후 베이비 건강 정보 등록으로 유도

### 진입 분기 (2026-09-04 운영자 확정)

- **초기 1회 (계정 생성·온보딩)**: 기록 채팅에서 진행 — 캐릭터 첫만남 + 첫 기록 유도
- **재방문 (로그인 + 채팅 기록 있음)**: 진입 시 **카메라(가림 ON)부터 열린 상태로 시작**
  — 아키텍처는 그대로 기록 채팅 본체이며, 그 위에 `CameraSheet`가 자동 오픈된 상태.
  닫으면 바로 채팅. (기획서의 "선체험 퍼널"은 온보딩 흐름에, "카메라 첫 화면"은 재방문 흐름에 대응)

## 탭 1 — 기록 (채팅 본체)

- 상대는 선택된 캐릭터(피피 or 푸푸) 1:1 단독챗. 텍스트 기록이 기본 단위.
- 유저 발화 → AI 파싱 → 채팅 안 **기록 카드** 제안 (별점 0~5 · 0.5단위 수정 가능,
  [기록 저장] 확정 전 미저장, 별점 수정 시 코멘트 갱신)
- **문진(팔로업) 최우선**: 증상 언급 시 판단 전에 되묻기 (한 턴 1~2개) — `07-cat-persona-voice.md` §0.5
- 이미지 첨부: 입력창 첨부(+) → 카메라/앨범 시트(`CameraSheet`)
  - 카메라 열리는 순간부터 가림 ON 디폴트 (모자이크 or 스티커, 채도 제거)
  - 화면 내 토글: 가리기 ON/OFF, 모자이크 ↔ 스티커 전환 (기본값은 설정 탭)
  - 앨범 업로드도 렌더 전 Canvas 가림 처리
  - AI 분석용 원본은 별도 저장 (마스킹 레이어와 원본 레이어 구분)
- AI 분석 2단 파이프라인: Vision 분석(상위 모델) → 페르소나 렌더링(경량 모델)
- 이상 소견 시 추가 질문(followUpQs): "오늘 뭐 드셨어요?" / "약 드시는 거 있으세요?" 등
- 기록 검색 연출: tool use 발동 시 캐릭터 고정 문구("잠깐 기록 좀 볼게냥 📖") 중간 말풍선

## 탭 2 — 히스토리

- **상단** 꺾은선 그래프 — X축 날짜(7일/30일), Y축 별점(0~5). 점 클릭 시 상세 팝업
- **중단** 캘린더 뷰 — 날짜별 상태 도트 (색+모양 병행, 색약 대응)
  - 양호(별점 4↑) `status.good` ● / 주의(2.5~3.5) `status.caution` ◐ / 경고(2↓) `status.warning` ▲
- **하단** AI 7일 총평 (기록 저장 시 1회 계산·저장, 조회 시 재사용)
- **장기 추적 피드백**: 누적 기반 경고 ("한 달 20회 이상 설사 → 병원 권유")
- **병원 방문 기록**: 방문 체크 → 호전/악화 추적 기준점, 캘린더에 표시
- 뷰 전환 7일/30일 (오늘 기준, 맨 오른쪽이 오늘) · 모드 전환 가로 스와이프
- **게스트는 열람 잠금** — "기록이 N개 쌓였어요 🔒" + 가입 유도 (기록은 자유, 열람이 보상)

## 탭 3 — 설정

```
├── 가리기 설정 (기본값: 모자이크 or 스티커 / 스티커 캐릭터 선택 / 기본 ON·OFF)
├── 테마 (시스템 · 라이트 · 다크)
├── 캐릭터 전환 (피피 ↔ 푸푸, 인수인계 연출)
├── 마이 건강 정보 등록/수정 — 프로필 3티어 (필수: 나이·성별·키·몸무게 / 선택: 음주·복용약·기저질환·생리 주기)
├── 마이 베이비 건강 정보 등록/수정
├── 다운로드 (일주일치 무료 / 전체·날짜·기간 = 인앱결제, 원본 이미지 포함 토글)
├── 드립 수위 / 소변 기록 ON·OFF
├── 언어 설정 (한국어 / English — 기기 언어 자동 동기화)
├── 계정 (로그인·로그아웃 / 게스트면 가입 유도 / 전 계정 회원탈퇴)
└── 개인정보 처리방침 / AI 학습 데이터 활용 동의 (분리 동의)
```

## PC 웹 분기 (조회 전용 뷰어)

- 카메라를 먼저 열지 않는다. **한 달 데이터를 보는 달력형 화면이 기본.**
- 카메라 기능은 오프 상태로 표시 — 안내는 캐릭터 말투: "카메라는 모바일에서 사용 가능합니다!"
  (알림창 텍스트 파일로 별도 관리)
- 열람 · 인쇄 · 리포트 다운로드 전용. 기록 입력 없음.
- **기억(노드) 관리 화면 — PC 웹 전용**:
  - 유저가 노드 목록 열람: "얘가 나에 대해 기억하는 것들"
  - 수동 관리: 노드 수정 · 삭제 · 잘못된 통합 분리 · 잊지 말 것 고정(핀)
  - 노드 상한(무료 30 / 프리미엄 200, 가안)·자동 정리 안내도 여기서만 노출
  - 모바일 앱/챗 화면에는 진입점 없음 — 캐릭터는 챗에서 기억 용량·정리를 언급하지 않는다 (몰입 유지)
