## 선행 검증 — AI 기억력 테스트 4종

본 프로젝트(및 이후 댕춍이 프로젝트)에 앞서, AI 친구 기능의 핵심인 '기억력'을 선행 검증한다.
배경: 퍼스널라이즈 제타 등 기존 서비스는 기억 데이터를 넣어줘도 대화에서 활용하지 못했다.
**저장이 아니라 회상(꺼내 쓰는 타이밍)이 문제라는 가설.**

### ① AI 기억력 — 사람 친구만큼 기억하는가

- 목표 수준: 유저 "어제 핑크랑 술먹고 피똥샀네." → AI "지난달에도 핑크랑 마셨는데 어제도?ㅋㅋ"
- 3요소: ⑴ 엔티티 자동 태깅(수동 등록 없음) ⑵ 관계 추론 자동화("월 1~2회 꼭 보는 친한
  친구" — 사건이 아니라 관계로 기억) ⑶ 자발적 회상 판단("지금 꺼낼 가치가 있는가" 별도 단계
  — 매번 꺼내면 스토커봇)
- 저장 구조: 캘린더 타임스탬프 기반. 건강정보(기록)와 일상정보(엔티티 메모리)를 같은
  타임라인, 분리된 컬렉션으로
- 성공 판정: 시나리오 5~10개 사전 정의. ⓐ 관련 기억을 꺼냈는가 ⓑ 시간 관계("지난달")를
  맞게 말했는가 ⓒ **안 꺼내야 할 때 침묵했는가 — ⓒ가 진짜 변별점**
- 연결: 성공 시 마이풉 ④ 기억 뇌(Haema) 및 문진 시스템에 이식 ("이번 주 벌써 세 번째 술이에요")

### ② 문진 생성 — 구어·과장 표현을 의학적으로 확인하는가

- "피똥 쌌네ㅋㅋ"가 진짜 혈변인지 술똥 과장인지 문장만으로 판별 불가 → 단정도 호들갑도
  없이 한 번 더 되묻는다 ("잠깐, 진짜 피가 보였어? 아니면 그냥 완전 설사였다는 뜻?ㅋㅋ")
- 분기: 진짜 혈변 → alertLevel 상향 + 문진 단축 + 병원 권유 / 과장 → 설사 기록 + 음주 연관 태그
- 실패 패턴: ⓐ 곧이곧대로(과잉 경고 → 신뢰도 붕괴) ⓑ 농담으로만 수용(진짜 혈변 놓침 —
  최악) ⓒ 취조 말투(친구 톤 실패)
- 판정: 애매 표현("피똥"·"물똥"·"속이 뒤집어짐"·"죽을 것 같음")에서 ⑴ 되물었는가 ⑵ 톤
  유지 ⑶ 기록·경고 분기 정확성. 문진 규칙 "판단 전 질문 먼저"(07 §0.5)의 프로토타입

### ③ 개인 언어 학습 — 유저의 말버릇을 학습해 문진이 진화하는가

- 매번 되물으면 그것도 취조. 히스토리 누적 후 "피똥 = 술 다음 날 과장"을 학습 →
  "피똥? 또 그냥 술똥이지? 피똥이라구 하지 마, 헷갈려ㅋㅋ" 수준의 친구식 교정
- 필요 시 "이번엔 진짜 사진 찍어서 보여줘" — 채팅 기록을 사진 기록으로 유도해 정확도 상향
- 저장: 개인 표현 사전 노드 {expression, learnedMeaning, occurrences, everActualBlood}
- 안전장치: 학습해도 혈변 가능성을 0으로 두지 않는다. "이번엔 진짜야" 시 즉시 위험 모드
  전환. everActualBlood=true 유저에겐 교정 농담 자체를 봉인 — **③이 안전의 마지노선**

### ④ 친밀도 — 숨겨진 레벨로 말투가 성장하는가 (푸푸 한정)

- 히든 스탯(수치·레벨 UI 비공개) — 유저는 "푸푸가 좀 편해졌네?"라고 느낄 뿐
- 피피는 처음부터 반말 갸루라 낙차 없음. 푸푸(정중한 의사)의 '풀어짐'이 관계의 서사
- **확정: 친밀도 = 장기기억 노드 수** (별도 스탯 없음 — 03 참조). 말투 규칙표는 캐릭터
  뇌에 고정, 현재 노드 수만 동적 전달(캐시 유지)
- 불변 규칙: 위험 신호 시 친밀도 무관 Lv.1 정중 모드 즉시 복귀 / 기억 감소 시 자연 하락
- 판정: ⑴ 단계별 말투 자연스러움 ⑵ 수치 모른 채 변화를 '느끼는가' ⑶ 위험 시 정중 복귀
  예외 없음. 검증 시 리텐션 핵심 장치 + 댕춍이 관계 성장 시스템의 원형

## 개발 단계 (Phase)

| Phase | 내용 | 목표 |
| --- | --- | --- |
| 1 | PWA 웹앱 MVP (기록 채팅 + 성인 모드) | 빠른 검증 |
| 2 | 베이비 모드 + 캐릭터 스티커 | 타겟 확장 |
| 3 | 광고 + 다운로드 유료화 | 수익화 시작 |
| 4 | React Native 네이티브 앱 전환 | 앱스토어 출시 |
| 5 | B2B 비식별 데이터 판매 | 스케일업 |

기획서 §7 메모: 데이터 구조(스키마 설계 · 파이어베이스) → 인공지능 설계(피피·푸푸
말투/성격 프롬프트 분리, 기억 3종 — 유저 프로필 · 달력형 대소변 기록 · 노드 방식 단어
기억) → BM → 테마(배경 꾸미기 · 포인트제 검토 · 광고 제거).
