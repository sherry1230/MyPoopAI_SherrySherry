## Phase 1 체크리스트

- [ ] Vite + React + Tailwind 초기 구동 (`npm install && npm run dev`)
- [ ] 디자인 토큰 적용 확인 (배경/텍스트/카드)
- [ ] 온보딩 화면 (성인/베이비 선택 → LocalStorage)
- [ ] 카메라 스트림 (WebRTC) 연결
- [ ] Canvas 실시간 모자이크
- [ ] 변기/기저귀 인식 (1차: 사용자가 영역 지정, 2차: 자동 인식)
- [ ] 촬영 → AI 분석 호출 (서버 경유) → 별점/코멘트
- [ ] 이상 소견 시 추가 질문 팝업
- [ ] 기록 저장 (LocalStorage)
- [ ] 히스토리 그래프 + 캘린더
- [ ] 설정 탭 기본 항목
- [ ] 반응형 4구간 확인 (Mobile / Tablet / Desktop / Wide)
