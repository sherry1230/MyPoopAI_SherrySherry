## v0.5 오로라·뉴트로 (기획서 확정 — 코드 반영 대기)

### 무드

낡은 신문지, 네온사인이 켜진 밤거리. 바탕은 빈티지 뉴스페이퍼처럼 차분하다 — 채도를
눌러둔 웜 뉴트럴과 더스티 로즈, 페이디드 데님. 소리 지르는 색은 하나도 없다
(음식을 연상시키는 쨍한 색은 처음부터 금지어).
그 위에 **빛은 아껴서 쓴다. 네온과 오로라는 면(fill)이 아니라 선(line)에만 허락된다.**
지금 살아있는 것 — 활성 카드, 포커스된 입력창 — 만이 오로라 라인을 두르고 은은하게 발광하고,
꺼진 것들은 불 꺼진 네온사인처럼 윤곽만 남는다.

### 테마

- 라이트/다크 — 기기 설정 동기화 기본, 수동 전환 가능
- 라이트: 화이트 바탕 + 핑크·라벤더 오로라 라인 (하이라이트 `#FFFFFF`)
- 다크: 쿨 그레이 `#1B1E23` + 블루 오로라 라인 (네온 시안 하이라이트 `#4FE2FF`)
- 상태 표시: 뮤트 신호등(올리브 · 번트 오렌지 · 브릭 레드) + 형태 구분으로 색약 대응
- 캐릭터: 피피(백묘) · 푸푸(흑묘) — UI 톤과 동일한 뮤트 팔레트로 통일

### 오로라 라인 CSS (확정)

```css
/* 일러 31° = CSS 59deg. 스톱 0·13·23·31·53·83·101% */

/* 라이트 모드 */
--aurora-line: linear-gradient(59deg,
  #E4ABCE 0%,
  #FFAFBD 13%,
  #FFFFFF 23%,   /* 하이라이트 */
  #FFAFBD 31%,
  #E4ABCE 53%,
  #B8A9C9 83%,
  #D8ACC4 101%
);

/* 다크 모드 — A안 시안 하이라이트 */
--aurora-line-dark: linear-gradient(59deg,
  #006B89 0%,
  #2C8EAD 13%,
  #4FE2FF 23%,   /* 네온 시안 하이라이트 */
  #2C8EAD 31%,
  #006B89 53%,
  #005490 83%,
  #38A1B8 101%
);
```

적용 패턴 (확정):

```css
/* 카드 테두리 (라인 2px) */
.aurora-card { border-radius: 18px; padding: 2px; background: var(--aurora-line); }
.aurora-card > .inner { background: var(--card-bg); border-radius: 16px; }

/* 입력창/필 테두리 (라인 1.5px) */
.aurora-pill { border-radius: 999px; padding: 1.5px; background: var(--aurora-line); }
.aurora-pill > .inner { background: var(--card-bg); border-radius: 999px; }

/* 글로우 — 포커스/활성 상태에만 켬 */
.aurora-glow--light { box-shadow: 0 0 10px rgba(228,171,206,.55), 0 0 24px rgba(255,175,189,.3); }
.aurora-glow--dark  { box-shadow: 0 0 10px rgba(79,226,255,.35), 0 0 24px rgba(0,169,234,.2); }

/* 다크 모드 스위칭 */
[data-theme="dark"] { --aurora-line: /* 다크 그라디언트로 교체 */; }
```

### 캐릭터 아트 스타일 (확정 — 피피 기준, 푸푸 동일 포맷 예정)

- **한국 뉴트로 빈티지 플랫 팝 프린트** — 1970~80년대 실크스크린 포스터 무드.
  가볍고 공기감 있게, 플랫 색면 + 최소한의 얇은 선, 바랜 종이 · 인쇄 그레인 · 할프톤 · CMYK 어긋남.
- 금지: 애니/치비, 3D, 동판화·판화·크로스해칭, 두꺼운 외곽선, 사진풍, 매끈한 디지털 마감, 네온·원색·어두운 배경.
- 피피 외형 아이덴티티 락은 `docs/07-cat-persona-voice.md` 참조.

## v0.4 레트로 세피아 (코드 현행 — colors.css 원본)

### 금지색 → 색 사용 규칙

v0.4에서 금지색 규정은 폐지. 원색·네온 등 **고채도 색의 면(채움) 사용 금지**만 유지.
모든 색은 70~80년대 빛바랜 뮤트 톤 — 기본 화면은 모노톤, 컬러는 포인트·캐릭터·상태에 소량.
(v0.5 확정 시에도 동일: 네온은 면이 아니라 선 — 프레임·포커스·활성 글로우에만.)
