## 반응형 (웹 우선)

| 구간 | 범위 | 레이아웃 |
| --- | --- | --- |
| Mobile | ≤ 599px | 1컬럼 · 하단 탭바 고정 · 패딩 16 · 촬영 버튼 72px |
| Tablet | 600–1023px | max 720 · 그래프+캘린더 2단 · 패딩 24 |
| Desktop | 1024–1439px | max 1080 · 좌측 사이드 내비 · 기록 상세 우측 패널 |
| Wide | ≥ 1440px | max 1200 · 사진 원본 확대 뷰어 · 그래프 확대 |

- 스페이싱: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
- 라운드: 8(칩) / 12(카드) / 16(모달) / 999(버튼)
- 터치 타겟 최소 44px
- 데스크톱에서 사진을 더 크고 자세히 볼 수 있어야 함 → 뷰어는 뷰포트 대응 `max-height`
