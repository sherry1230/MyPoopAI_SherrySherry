# 00 · 제품 개요

## 왜 만드는가 (기획 의도)

- 소아과 의사들의 공공연한 직업적 수난: 초보 엄마들이 시도 때도 없이 아기 변 사진을
  들이밀며 "선생님, 이 색깔 괜찮은 건가요?"를 묻는다. 받는 쪽 안구 건강도, 아이 건강
  앞에서 작아지는 부모 마음도 모두 딱하다. → **이 정도 가벼운 상담이면 지금의 AI가 받아줄 수 있다.**
- 아기만을 위한 것은 아니다. 술과 가까운 사람, 예민한 장을 가진 사람, 이미 병원에
  다니는 환자(병명·복용약을 저장해 두고 민망함 없이 먼저 물어볼 상대)에게도 유용하다.
- 의료 앱이 아니다. "병원에 가봐야 하나?" 하는 의문이 슬며시 고개를 들 때
  은밀하게 꺼내 쓰는 **기록·참고 도구**. 기록을 모아 다운로드해 진료실에 점잖게 내밀 수 있다.

**제품 재정의: "한마디를 듣고 되물어서 기록을 완성하는 존재."**
(예: "어제 야근하고 잠을 못 자서 오늘 똥이 엄청 얇은데 문제 생긴 건 아니겠지?" → AI가 되물어 기록 완성)

## 개발 우선순위 (기획서 '주요 순위')

### 1. 데이터 추적

- 대소변에서 간략히 알 수 있는 건강 정보만 저장. 일반인은 브리스톨 척도를 몰라도 된다.
- **사용자 프로필 3티어**:
  - 필수(온보딩): 나이 · 성별 · 키 · 몸무게 — 이것만으로 해석 정확도가 크게 상승.
    성별은 호르몬 주기·요로감염·전립선 등 소변 해석 기준이 갈리므로 필수.
  - 선택(설정): 음주 빈도 · 복용약 · 기저질환/병명 · (여성) 생리 주기.
    복용약은 변 색을 직접 바꾸는 요인이라 오탐 방지에 필수급.
  - 확장(추후): 운동량 · 인바디 · 지방간 수치 등 — v1에는 넣지 않되 스키마에 확장 슬롯만 예약.
- **장기 추적**: "오늘 설사네" 수준이 아니라 "한 달에 20회 이상 설사 — 병원에 가봐야 한다"
  수준의 누적 기반 피드백.
- **병원 방문 기록**: 다녀왔다고 체크하면 AI가 기억 — 방문 후 호전/악화 추적의 기준점.
- 위 모든 기록은 **달력과 함께 저장**되는 구조가 핵심.

### 2. AI 캐릭터의 가벼운 상담

- 고양이 캐릭터 피피 · 푸푸 — 캐릭터 사업까지 염두. 외형·프롬프트는 기획서 세부기획/아트 문서.
- **대화하듯 기록**: 사진 없이 "나 오늘 설사했는데, 어제 술 먹고 자서 그런가?" 같은
  채팅만으로 상태를 분류·저장 — 사진 촬영을 원치 않는 사용자를 위한 핵심 차별점.
- 프로필 연동 상담: 저장된 병명·복용약 기반으로 의사에게 묻기 민망한 것을 먼저 질문.
- 건강똥드립: 건강 판정일 때만, 운영자 등록 드립 풀에서 랜덤. AI 즉석 창작 금지. 나쁜 결과엔 절대 금지.
- ⚠ 검토 필요 — 혈변 판별: CV로 확실히 구분 가능한가(고춧가루 혼동?). 어려우면 AI가
  확인 질문("고춧가루 드셨나요?", 여성+생리 주기 미등록 시 "생리 중이신가요?") 방식 검토.

### 3. 안구 보호

- 촬영 시 기저귀·아기 변기·성인 변기 내부를 추적해 굵은 모자이크/고양이 스티커로 즉시 가리고 채도 제거.
- 카메라 오픈 순간부터 가림 적용 (기본 ON).
- 단, AI 분석용 원본(비마스킹)은 별도 저장 — 마스킹 레이어와 원본 레이어 구분 필수.

### 4. 멀티 환경

- PC 웹: 카메라를 먼저 열지 않는다. 한 달 데이터를 보는 **달력형 화면이 기본**,
  카메라는 오프 표시("카메라는 모바일에서 사용 가능합니다!").
- 안내 문구는 피피·푸푸 말투로 통일, **알림창 텍스트 파일 별도 관리**.
- 데이터 내려받기: 일주일치 무료 / 전체는 인앱결제. 원본 이미지 포함·불포함 토글 — 진료실 제출 시나리오의 구현.

## 선행 검증 — AI 기억력 테스트 (상세는 04-roadmap)

본 프로젝트(및 이후 댕춍이 프로젝트)에 앞서 AI 친구 기능의 핵심 '기억력'을 검증한다.
① 기억력(엔티티 태깅·관계 추론·자발적 회상) ② 문진 생성 ③ 개인 언어 학습 ④ 친밀도(푸푸 한정).

## 기능 요약

1. **기록(핵심)** — 사진 촬영 기록(실시간 마스킹) + 채팅 기록(사진 없이 대화로).
   AI 분석 파이프라인 2단: ① Vision 분석(상위 모델, 이미지→구조화 데이터)
   ② 페르소나 렌더링(경량 모델, 캐릭터 말투 출력). 분석 로직과 말투는 분리 관리.
2. **AI 캐릭터** — 피피·푸푸, 잡담 친구, 상담 챗(프로필 연동), 건강똥드립
3. **히스토리** — 달력 뷰(일/월), 장기 추적 피드백, 병원 방문 기록
4. **프로필** — 필수(나이·성별·키·몸무게) / 선택(음주·복용약·기저질환·생리 주기)
5. **데이터 내려받기** — 일주일치 무료 / 전체 인앱결제, 원본 포함 토글
6. **모드** — My 💩 (성인) / My Baby 💩 (베이비)
7. **플랫폼** — 모바일 풀 기능 / PC 웹 달력 뷰 중심·카메라 오프
8. **수익 모델** — 아래 참조

## 수익 모델 (기획서 9/4판)

| 구분 | 내용 |
| --- | --- |
| 무료 | 사진 분석·저장 1일 1회 |
| 추가 분석 | 리워드 광고 시청. 🎰 **3% 확률 광고 면제** — "오늘은 그냥 통과!" + 고양이 윙크 (변동비율 보상) |
| 프리미엄 (월 1,100원) | 광고 제거 + 1일 분석 상한 상향(예: 1→5회). ⚠ 무제한 아님 — API 원가 방어 위해 일일 상한 유지 |
| 인앱결제 (단건) | 전체 데이터 내려받기 |
| 노드 상한 | 장기기억 노드 무료 30 / 프리미엄 200 (가안) — "더 친해지고 싶으면" = 구독 동기 |
| B2B 데이터 | 비식별 데이터 의료/교육 기관 (장기) |
| 캐릭터 IP | 굿즈 · 라이선스 (장기) |

## 접근성 원칙

- 어르신·환자도 쓸 수 있어야 한다. 글자 크기, 터치 타겟 44px 이상, 용어는 쉬운 한국어.
- 로그인 없이 게스트로 기록 기능 즉시 사용 (히스토리 열람 잠금은 의도된 정책).
- 언어: 기기 설정 자동 동기화, 수동 전환은 한국어 / English.
