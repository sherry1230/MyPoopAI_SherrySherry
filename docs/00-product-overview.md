# 00 · 제품 개요

## 왜 만드는가

- 의사들이 지인·이웃에게서 아이 대변 사진을 갑자기 받는 일이 많다. 받는 쪽도 괴롭고, 보내는 부모 마음도 이해가 간다.
- 반대로 자기 대변을 직접 보기 싫은 사람도 많다.
- 암 환자처럼 장 건강이 걱정되지만 의사에게 매번 묻기 어려운 사람도 있다.

→ **직접 보지 않아도, 남에게 보내지 않아도 되는 장 건강 체크.**

## 핵심 컨셉

- 카메라가 변기(또는 기저귀)를 인식하면 **카메라가 켜지는 시점부터** 모자이크 또는 캐릭터 스티커로 가린다.
- 가리기 기본값 ON. 사용자가 원하면 개별/전체 OFF 가능.
- 원본은 AI만 분석. 저장/노출되는 이미지는 가리기 처리본이 기본.

## 타겟

1. 초보 부모 (아기 변이 걱정돼 의사에게 사진을 보내던 사람)
2. 장 건강이 걱정되지만 상담이 어려운 성인 (암 환자, 어르신 포함)
3. 자기 대변을 보기 싫지만 건강은 체크하고 싶은 사람

## 접근성 원칙

- 어르신·환자도 쓸 수 있어야 한다. 글자 크기, 터치 타겟 44px 이상, 용어는 쉬운 한국어.
- 로그인 없이 게스트로 전 기능 사용 가능.
- 언어: 기기 설정 자동 동기화, 수동 전환은 한국어 / English.
